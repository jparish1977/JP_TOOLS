# System tools check.py shells out to: the ones pip, npm and composer cannot
# install. One per line: TOOL MIN_VERSION APT_PACKAGE WINDOWS_PACKAGE.
#
# requirements-dev.txt declares the Python runners, package.json the JS ones
# and composer.json the PHP ones; this declares the rest, so there is one
# manifest a person can read, install from and diff (METHODOLOGY 7). A check
# whose tool is missing exits 2, but learning a machine needs a package from a
# refused commit is the slow way, so install.sh and CI read this file.
#
# MIN_VERSION is what the arm was tested on, not a pin: apt ships one version
# per release. Without cppcheck, a C/C++ file exits 2 until it is installed.
#
# A TOOL of php:EXT is a PHP extension, not a command: composer.json's
# iteration8/utilities (find-dupes.php's library) requires these, and
# `composer install` stops without them. MIN_VERSION is the PHP they were
# tested on; on Windows they ship with PHP, enabled in php.ini.
#
# pwsh is PowerShell 7. Its apt package, `powershell`, comes from Microsoft's
# repository (packages.microsoft.com), not Ubuntu's; `snap install powershell
# --classic` is the same release. Without it a .ps1 file exits 2. A TOOL of
# pwsh:MODULE is a PowerShell module, installed from the PowerShell Gallery:
#     pwsh -c 'Install-Module NAME -RequiredVersion VERSION -Scope CurrentUser'
# and here VERSION is the pin: the Gallery serves every release.
