# install` line in a CI workflow. That is not a declaration a person can read,

#
# The cost of the gap is silent. A missing runner is reported as
# "unavailable", which contributes no issues, and _summarize counts only
# issues -- so a run with an arm that never executed is indistinguishable in
# the summary and the exit code from a run where everything passed.
#
# Pins are deliberate. Unpinned linters turn a green build red months later in
# whichever PR happens to be open, with no code change.
